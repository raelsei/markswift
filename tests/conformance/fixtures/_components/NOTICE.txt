Component corpus sources (compiled into ../components/ by tests/conformance/tailwind-v4.ts)

- shadcn-*.html (23 components): static SSR markup of shadcn/ui "radix-nova" components (neutral theme), built in
  research/corpora/shadcn; shadcn-list-24.html is hand-written from the same item and badge markup. shadcn-spinner.html
  and shadcn-skeleton.html carry `markswift-motion` frame times.
- globals.css: the shadcn/ui theme and Tailwind entry sheet from the same build (tw-animate-css and shadcn/tailwind.css
  inlined), with the Geist font and dark mode rewritten for offline capture.
- tw-cards.html, tw-form.html, tw-settings.html: Markswift's own test pages.

Geist: SIL OFL, see ../assets/OFL-Geist.txt; Tailwind CSS: MIT, banner kept in each compiled page; tw-* pages: Markswift's own.
